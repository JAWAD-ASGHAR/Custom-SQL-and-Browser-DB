# Mini DB

A simple database tool that runs right in your web browser. Create tables, manage your data, and run queries - all without installing anything.

## What is Mini DB?

Mini DB is a visual database manager that lets you:
- Create tables and organize your data
- Add, edit, and delete rows
- Connect tables together with relationships
- Run SQL queries to find and filter your data
- View your database structure visually

Everything is stored in your browser, so your data stays private and local to you.

## Getting Started

1. Install the required packages:
   ```
   npm install
   ```

2. Start the application:
   ```
   npm run dev
   ```

3. Open your browser to the URL shown (typically `http://localhost:5173`)

That's it! You're ready to start creating your database.

## How to Use

### Creating Tables
Click the "Create Table" button and give your table a name. Add columns with different data types (text, numbers, dates, etc.) to organize your information.

### Adding Data
Once you have a table, click "Add Row" to start entering data. You can edit any cell by clicking on it.

### Connecting Tables
Use the "Create Relation" button to link tables together. This lets you reference data from one table in another, just like connecting ideas.

### Running Queries
Type SQL queries in the query editor to search, filter, and analyze your data. The app includes suggested queries to help you get started.

### Viewing Relationships
Click "View Relations" to see a visual diagram of how all your tables are connected.

## Features

- **Simple Interface** - Easy to use, no technical knowledge required
- **Visual Database** - See your data structure at a glance
- **SQL Queries** - Powerful search and filtering capabilities
- **Relationships** - Connect related data across tables
- **Local Storage** - Your data stays on your computer
- **Export/Import** - Save and share your database
